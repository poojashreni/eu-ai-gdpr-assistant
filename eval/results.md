## How to read this

- hit@k: share of in-scope questions where at least one expected provision is among the top-k retrieved results (k = top_k after DE/EN de-duplication). Out-of-scope questions are excluded; *n* says how many questions a number is based on.
- hit@k (paragraph) only counts questions whose gold expectation names a paragraph.
- "by text covered" (naive only): a naive piece is labelled with the provision it starts in, but its text may run into the next one. This variant counts a hit if the expected provision's text is anywhere in a retrieved piece. The plain row is what a citation would show.
- Retrieval latency excludes model loading (one warm-up query runs first).
- Answer metrics need an LLM (GOOGLE_API_KEY) and run once a key is available.
